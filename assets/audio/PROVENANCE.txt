Vibe String - Thread Test 120 - original development fixture
Created: 2026-10-05

This short instrumental was AI-composed in source code and programmatically
synthesized with oscillators and seeded noise. It was not generated by a neural
audio model. No recordings, imported samples, source-game music, voices, melodies,
characters, artwork or other assets were used as inputs. It is a development
fixture, not a recreation of a Vib-Ribbon song.

Authoring: OpenAI Codex, for this repository at the user's request.
Source: tools/generate_dev_track.rs
Pseudo-random seed: 0x51A72026 (xorshift32).
Format: 48,000 Hz, 16-bit PCM, mono WAV. Duration: 70 seconds.
Tempo: 120 BPM, 4/4. Eight count-in beats, 32 music bars, two-second tail.
Chart: assets/charts/line_test_120.json, version 1, 68 events.
Event frames count decoded PCM sample frames from the first frame of the WAV.
The chart's audio path is relative to its containing directory. Frame timestamps
specify the required input/impact time; applications choose their own lookahead.
Pairs use bitwise OR of action masks. Every event has a synthesized accent.

Reproduce from the repository root with Cargo:
  cargo run --locked --release -p vibe-string-tools --bin generate-dev-track

Alternatively, with PowerShell and an installed Rust compiler:
  $trackExe = Join-Path $env:TEMP 'vibe-string-generate-dev-track.exe'
  rustc -O -C debuginfo=0 tools/generate_dev_track.rs -o $trackExe
  if ($LASTEXITCODE -ne 0) { throw 'Compilation failed' }
  & $trackExe

The generator needs only the Rust standard library. It writes the WAV and JSON.
Seed, note sequence and chart are fixed. Floating-point transcendental functions
can differ slightly between compiler/platform versions, so byte-identical WAVs
across platforms are not promised. Integer chart timing is exact.
